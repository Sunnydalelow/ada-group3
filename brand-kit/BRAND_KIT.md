## Logo

- **Format:** Horizontal wordmark — "American Diabetes Association"
- **Current variation:** 85th anniversary mark (founded 1940)
- **Primary color:** ADA Red (`#A6192E`)
- **Usage:** Always use on white or very light backgrounds; do not recolor or distort

### Logo Files

| File | Use Case |
|------|----------|
| `brand-kit/logos/ada-logo-full-color.svg` | Primary logo — use on white/light backgrounds |
| `brand-kit/logos/ada-logo-white.svg` | Reversed logo — use on dark/colored backgrounds |
| `public/ada-logo.svg` | Web app header logo (same as full-color) |

### Logo Guidelines

- **Clear space:** Maintain minimum padding equal to the height of the "A" in "Association"
- **Minimum size:** Do not display smaller than 120px wide on web
- **Don't:** Stretch, rotate, add effects, change colors, or place on busy backgrounds
- **Dark backgrounds:** Use the white (`ada-logo-white.svg`) version only

## Voice & Tone

### Pillars

1. **Groundbreaking Research**
2. **Bold Advocacy**
3. **Trusted Education**
4. **Meaningful Connections**

### Tone Guidelines

| Attribute | Do | Don't |
|-----------|----|----|
| Empowering | "You can take control of your health" | "You should follow these rules" |
| Hopeful but urgent | "There's hope — and you don't have to do it alone" | Doom-and-gloom statistics without a path forward |
| Accessible | Plain language, short sentences | Clinical jargon in consumer content |
| Person-first | "People living with diabetes" | "Diabetics" |
| Community-centered | "Together", "Unite", "Join us" | Isolating language |

### For Agent / Conversational UI

- Use **warm, supportive, inviting** tone (consumer audience)
- Always use **person-first language**
- Lead with empathy, follow with action
- Keep responses concise — respect the user's time
- When uncertain, guide to professional resources rather than guessing
